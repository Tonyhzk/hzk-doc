# 编写文档

这份指南介绍如何组织 Markdown 文件，并让文档中的链接和素材正常显示。

## 目录与文件名

文件夹对应站点分类，文件名对应目录中的标题。普通文件不需要特殊 ID，也不会因为浏览而被重命名。

后台的排序操作只调整显示顺序，不更改文件名。隐藏文件不会出现在公开文档目录中。

## Markdown 排版

使用标题组织内容，用段落解释细节。表格适合展示简短的可枚举信息。

```go
package main

import "fmt"

func main() {
	fmt.Println("欢迎使用 hzk-doc")
}
```

代码块会保留缩进，可以直接复制。

- [x] 使用有意义的标题。
- [x] 将相关文档放入同一文件夹。
- [ ] 发布前检查文档中的素材和链接。

## 文档链接

普通相对路径以当前文档所在目录为起点，例如 [返回开始使用](../开始使用.md)。页内链接可以跳转到对应的标题。

## 图片与附件

统一素材可以放入文档根目录下的 `assets/` 文件夹，并使用 `assets/文件名` 引用；这个写法不受当前文档所在层级影响。其他相对路径按文档所在目录解析。

上传文件时同名文件不会被覆盖。修改 Markdown、HTML 或文本文件，请使用后台编辑功能。

## 安全与发布

阅读页面对内容做安全处理，HTML 文档在隔离区域预览，不运行文档内的脚本。公开阅读无需管理员登录，所以不要把凭据或私密资料放进公开文档目录。

需要精确展示复杂 Office 排版时，可以同时提供 PDF 和原文件。
