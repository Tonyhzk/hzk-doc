# 开始使用

hzk-doc 把本地文件整理成可浏览、可搜索的文档站，也可以通过后台维护文档。

## 阅读文档

从左侧目录选择内容，使用右侧目录跳转到文章章节。手机上可以通过目录按钮展开导航。

按 **⌘ K** 或 **Ctrl K** 打开搜索，按标题快速查找，或者切换到全文搜索。页面支持明暗主题，代码块可以单独复制。

## 管理内容

启用管理员密码后，从页面进入后台。后台可以创建 Markdown 文档和文件夹、编辑文本、上传资料，以及调整同一目录下的显示顺序。

修改文档后，阅读目录和搜索会更新。文件仍保存在配置的文档目录中，不需要导入数据库。

## 支持的文件

| 格式 | 阅读方式 |
| --- | --- |
| Markdown、纯文本 | 直接阅读 |
| HTML | 隔离页面预览 |
| PDF、图片 | 在线查看，也可下载 |
| DOCX、XLSX、PPTX | 内容预览，也可下载原文件 |
| 音频、视频 | 浏览器播放器 |

Office 预览用于快速阅读，不替代桌面软件的精确排版。音视频播放取决于浏览器支持的编码。
